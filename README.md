## About me

I like turning ideas into things people can actually use.

My work sits at an unusual intersection: **insurance, automation, web products, AI-assisted development, visual experiences, and reflective/spiritual projects.** I am as interested in understanding a real-world problem as I am in building the software around it.

I work with a simple principle:

> **A good idea is only the beginning. Build it, test it, refine it, and make it useful.**

I also enjoy exploring the quieter side of technology: interactive experiences, visual worlds, symbolism, reflection, and the question of how digital spaces can make people *feel* something rather than simply click something.

## 🔥 Projects that represent me

### 🛡️ [BimaNiti](https://bimaniti.in)
An insurance and market-insights platform focused on the Indian insurance ecosystem.

BimaNiti is more than a content website in my eyes. It is an experiment in building a structured knowledge system around insurance: publishing, SEO, internal linking, source discovery, static generation, automation, and scalable content workflows.

**Stack / approach:** Vanilla HTML, CSS & JavaScript · Node.js · JSON content architecture · GitHub Actions · Cloudflare Pages · structured data · automated static generation.

## 🧩 How I like to build

**01 · Start with the problem**  
Not the framework. Not the trend. The actual problem.

**02 · Build the smallest useful version**  
Get something real in front of people quickly.

**03 · Make the boring parts disappear**  
Automate repetitive work wherever sensible.

**04 · Make information discoverable**  
Good UX is not only visual. Structure, search, SEO, navigation, and clarity matter.

**05 · Keep experimenting**  
Some of my best ideas come from building things that were never part of the original plan.
